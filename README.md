# profile-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。
名前年齢趣味の３つが確認できるサイトを作成した
コントローラーやルーティングをつなぎ合わせてBLADEを使用しページを表示した

## 使用技術
- PHP 8.x
- Laravel 10.x
- Blade テンプレート
-グーグルジェミニ
-コーチテックのAI

## 学んだこと
- コントローラーからルーティングにあるURLとつなげる方法
- ルーティングでつなげたURLをviewを使ってデータをつなげること
- Bladeを使うと、変数を表示できること
- 404notfoundが表示されたとしても、コードの綴りミスやセミコロンの抜けなどを修正すれば表示できることを学んだ

## 動作確認
http://localhost/profileに実際アクセスしてみた
